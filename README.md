# ATOM Air Timer

M5Stack ATOM MatrixとENV-IIIセンサーユニットを使用した、室内環境モニター付きタイマーです。

5×5のLEDで室内の温度・湿度に応じた快適度と、タイマーの残り時間を表示します。

## 主な機能

- 温度・湿度による室内環境のモニタリング
- LEDの色と点滅による快適度表示
- 3分・15分・30分・60分のタイマー
- ボタンの短押し・長押しによる操作
- LEDによるタイマーの残り時間表示
- タイマー終了時の虹色アニメーション

## 使い方

### ボタン操作

ATOM Matrix本体のボタンを使用します。

| 状態 | 短押し | 長押し |
|---|---|---|
| 待機中 | タイマー時間の切り替え | タイマー開始 |
| タイマー動作中 | 操作なし | 最初からやり直し |
| タイマー終了後 | 待機状態に戻る | 同じ時間で再スタート |

タイマーの初期設定は60分です。

待機中に短押しすると、3分 → 15分 → 30分 → 60分の順番で切り替わります。

一時停止・再開機能はありません。

### タイマー時間の選択

時間を切り替えると、約2秒間、オレンジ色のLEDで選択時間を表示します。

| 時間 | LED点灯数 |
|---|---|
| 3分 | 3個 |
| 15分 | 8個 |
| 30分 | 15個 |
| 60分 | 24個 |

表示終了後は、通常の室内環境表示に戻ります。

### タイマー動作中

- 24個のLEDで残り時間を表示します。
- 残り時間に応じてLEDが減少します。
- LEDの色は現在の室内環境に応じて変化します。
- 先頭のLEDは白色に点滅し、タイマー動作中であることを示します。
- 長押しすると、選択中の時間で最初からやり直します。

### タイマー終了時

タイマーが終了すると、LEDの中心から外側へ虹色が広がるアニメーションを繰り返します。

短押しすると終了表示を解除し、待機状態に戻ります。

## 室内環境の表示

ENV-IIIセンサーから温度と湿度を取得し、約2秒ごとに快適度を更新します。

### LEDの色

| 色 | 状態 |
|---|---|
| 緑 | 快適 |
| 青 | 寒い、または乾燥している |
| 赤 | 暑い、または湿度が高い |

### 快適度の判定

| 状態 | 温度 | 湿度 |
|---|---|---|
| 快適 | 18℃超〜28℃未満 | 35%超〜65%未満 |
| 注意 | 18℃以下、28℃以上 | 35%以下、65%以上 |
| 警告 | 15℃以下、30℃以上 | 25%以下、75%以上 |

温度・湿度のいずれかが条件に該当すると、その状態として判定します。警告条件は注意条件より優先されます。

暑さ・高湿度と寒さ・乾燥の条件が同時に成立する場合は、赤色を優先します。

### LEDの表示方法

| 快適度 | 表示 |
|---|---|
| 快適 | 暗めに常時点灯 |
| 注意 | 明るく常時点灯 |
| 警告 | 点滅 |

※ 判定閾値は暫定的な設定値です。
